R113 - Hébergement

TP 2 - Menu JS et animaux

Présentation : C'est un projet étant réalisé dans le cadre d'un TP d'hébergement en MMi 1.

Il faut ainsi créer des liens relatifs permettant de naviguer entre plusieurs pages consacrées aux chats et chiens.

Objectifs principaux :

- Créer une arborescence de fichiers organisée
- Réaliser plusieurs pages HTML
- Mettre en place des liens relatifs entre les différentes pages
- Intégrer des images de chats et chiens
- Ajouter des icônes SVG dans les menus de navigation grâce aux pseudo-éléments CSS
- Mettre en forme les images et les menus avec CSS

Langages utilisés : 

- HTML5
- CSS3
- SVG
- Netlify
